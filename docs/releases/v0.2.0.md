# NEXUS AI v0.2.0: permission-aware hybrid RAG with measured evaluation

**Scope:** Phase 1 (MVP) and Phase 2 (advanced enterprise hybrid RAG). This is a **local demo, not production-ready**. All data is synthetic.

## Highlights

- **Four retrieval modes**, each with authorization inside the SQL statement that ranks and LIMITs:
  - `bm25` (Python baseline);
  - `lexical` (PostgreSQL FTS, GIN);
  - `semantic` (pgvector, local `multilingual-e5-small`, `vector(384)`);
  - `hybrid` (FTS + semantic fused with Reciprocal Rank Fusion; the default on PostgreSQL).
- **Evidence-first answers:**
  - query-selected sentences of the authorized hits are quoted verbatim with `[S#]` citations;
  - a dev-calibrated evidence-sufficiency policy returns `no_evidence` instead of guessing;
  - the optional LLM path accepts only answers whose citations resolve to supplied sources, and otherwise falls back explicitly to the verbatim quotes.
- **Measured, not claimed:**
  - 100 labeled questions (dev/test), Recall/Precision/MRR/nDCG with bootstrap CIs;
  - an RRF ablation, abstention calibration, and citation and security evaluation with an independent ACL oracle;
  - mandatory CI gates. The published numbers are generated, and a test fails if the docs drift from the stored report.

## Results (held-out test split, from `eval/reports/latest.json`)

| Mode | Recall@5 | nDCG@5 | MRR@10 |
|---|---|---|---|
| BM25 | 0.760 | 0.701 | 0.709 |
| PostgreSQL FTS | 0.797 | 0.738 | 0.732 |
| Semantic | 0.850 | 0.737 | 0.720 |
| Hybrid RRF | 0.809 | 0.734 | 0.730 |

- **No mode is significantly better than another.** Every paired bootstrap CI contains 0, on 41 answerable test questions.
- **Hybrid evidence policy on test:**
  - refuses 9/9 unanswerable questions;
  - answers 33/41 answerable ones (answerability precision 1.000).
- **Offline answer fact recall on test:** 0.333 → 0.590 with query-aware quoting. End-to-end with the policy (CI metric): 0.538.
- **Authorization violations: 0.** The check covered 400 retrieval runs including all candidates, 400 API responses, citations and 396 captured LLM prompts.

## Known limitations

These are outside the Phase 1–2 scope and planned for v0.3/v0.4:
- **Demo authentication:** no OIDC, no rate limiting.
- **Authorization:** no PostgreSQL row-level security.
- **Documents:** no OCR, layout or table extraction; contract fields are regex-based.
- **Retrieval:** no reranker, no ANN index.
- **Ingestion:** no background workers.
- **LLM:** the optional OpenAI path is verified only against a fake client. No live call and no LLM answer-quality evaluation exist, and citation validation checks markers, not claim-level grounding.
- **Evaluation:** the corpus is small and synthetic (59 chunks), so confidence intervals are wide.
- **Frontend container:** it runs the Vite development server.
